Tentang Sistem

Teknologi Modern untuk Pemetaan Pendidikan

WebGIS SMPN Ternate dibangun dengan stack teknologi web modern untuk performa dan kemudahan akses terbaik.

  • Peta berbasis Leaflet.js dengan tile layer OpenStreetMap beresolusi tinggi
  • Backend PHP + MySQL dengan arsitektur REST API untuk data sekolah dan fasilitas
  • Sistem autentikasi multi-role: Admin (pengelola penuh) dan User (akses baca)
  • Database relasional mencakup tabel smpn, kelurahan, kecamatan, fasilitas, dan pengguna
  • Responsif untuk desktop maupun perangkat mobile dengan layout adaptif
  • API endpoint terstruktur untuk get, tambah, edit, hapus, dan pencarian data sekolah
🗄️
Database Terintegrasi

Tabel smpn, kelurahan, kecamatan, dan fasilitas saling terhubung dengan foreign key untuk integritas data yang solid.

🔐
Autentikasi Aman

Password ter-hash dengan password_verify() PHP. Login bisa menggunakan username atau email.

🌐
REST API Lengkap

Endpoint /api/ untuk get_sekolah, get_nearest, get_fasilitas, search, tambah, edit, dan hapus data.

Nilai Nearest Neighbor Ratio (NNR)
Clustered (0) Random (1) Seragam (2.15)
🔄 Pola ditentukan dari data real
Metode Analisis

Nearest Neighbor Analysis

Sistem menggunakan metode NNA dengan formula Haversine untuk mengklasifikasikan pola persebaran sekolah.

1
Hitung Jarak Minimum

Untuk setiap sekolah, cari jarak terdekat ke sekolah lain menggunakan rumus Haversine (mempertimbangkan kelengkungan Bumi).

2
Rata-rata Jarak Observasi

Hitung rata-rata semua jarak minimum untuk mendapatkan nilai jarak observasi aktual di lapangan.

3
Bandingkan dengan Jarak Acak

Hitung jarak rata-rata teoritis berdasarkan densitas sekolah, lalu bagi observasi dengan teoritis untuk nilai NNR.

4
Klasifikasi Pola

NNR < 1 = Clustered (mengelompok), NNR ≈ 1 = Random (acak), NNR > 1 = Uniform (seragam/tersebar merata).
